1. Basic operations

1 ls list

command [-options] parameter ...
Options are usually given with a ‘-‘ sign, -h, and sometimes ‘–’ is used to use the full name, –help

ls -a Show hidden files
ls -R displays subdirectory files
ls -F displays file type
The -F option adds a forward slash (/) after the directory name to make it easier for users to distinguish in the output. Similarly, it also adds an asterisk (*) after an executable file (such as the my_script file above) to help users find out which files can be run on the system
ls -i displays the file inode encoding

Wildcard

ls -l t?st replaces a character
ls -l t*st replaces multiple characters
ls -l t[abc]st Replace with abc
ls -l t[a-c]st Replace with a through c
ls -l t[!d]st is replaced with d
pwd print working directory
pwd -P If you are in a linked folder, simple pwd will appear in the wrong location. Add the -P option to get the correct path.

6. Output and input

A command will display output on the terminal monitor. Correct output will point to the STDOUT file, and incorrect output will point to the STDERR file.

  • standard file descriptor
    0 standard input 1 standard output 2 standard error
    ls file1 file2 file3 1>out 2>err 1 points to the correct output, 2 points to the incorrect output. If not specified, both correct and incorrect output will be output to the terminal.
    ls file1 file2 file3 &>both & will output both

  • redirect output
    If you intentionally generate error messages in your script, you can redirect a single line of output to STDERR. This simply requires redirecting output to the STDERR file descriptor using the output redirection symbol. When redirecting to a file descriptor, you must precede the file descriptor index value with an &:
    echo "This is an error message" >&2

  • exec command
    The exec command starts a new shell and redirects the STDOUT file descriptor to the specified file, such as exec 2>error
    exec 0<inputfile This allows the script to get input in the file testfile instead of the keyboard. The previous read command read data 0 from STDIN, which is the data entered through the keyboard. Redirecting 0 to inputfile here means that the data will be read from here.
    exec 3>file3out You can customize a descriptor so that the output you want to output can be placed within the 3 symbol later. echo "This should be stored in a file" >&3 can maintain the normal output of the display and redirect specific information to a specified file (such as a log file)

  • Fantastic little features

  • /dev/null is like a trash can
    echo "This is an error message" > /dev/null will discard the data
    cat /dev/null > testfile This will directly clear the file contents without re-creating it.

  • mktemp testfile.XXXXXX will fill in any characters and create a file
    mktemp -t testfile.XXXXXX will create a file in the system’s temporary directory /tmp/test.XXXXXX
    mktemp -d testdir.XXXXXX will fill in any characters and create a folder

  • tee test is like a T-to-interface
    data | tee test will be output to the screen and the test file at the same time (>test)
    data | tee -a test will not overwrite test(>>test)

9. sed command

It should be noted that the sed command will not modify the original file, but the output in the terminal will change. You can use redirection to output the sed-modified file or use the -i option to directly modify the file content

  • Used to modify text in batches
    sed 's/old/new/' test.txt s is the replacement command
    sed -e 's/old1/new1/; s/old2/new2/' test.txt Multiple modifications, pay attention to semicolons and single quotes
    sed -f txt.sed test.txt Put s/old1/new1/ into txt.sed and use the -f option to make a lot of modifications
    sed 'd' test.txt d is the delete command Use with caution
    sed 'i\text' and sed 'a\text' add a line before and after the specified line respectively.

  • Command group If you need to execute multiple commands in a single line, you can use curly braces to group them together

  • Replacement flag
    sed 's/pattern/replacement/flags flag is a replacement flag. There are four types that can be written together.

  • Number specifies the number in the text
    echo -e "test1 test1 test2 \ntest3 test4"|sed 's/test1/new/2'
    ->test1 new test2
    ->test3 test4
    -g replace all
    echo -e "test1 test1 test2 \ntest3 test4"|sed 's/test1/new/g'
    ->new new test2
    ->test3 test4
    -p prints out the replaced lines -n means only print matching lines
    echo -e "test1 test1 test2 \ntest3 test4"|sed -n 's/test1/new/gp'
    ->new new test2
    -w file writes the replacement results to a file

  • sed 's|//ccc0|\nchain->Add(\"${FILE_PATH}\")|g'When / will cause confusion, you can use some other symbol to separate it

  • Specify the row address Same applies to i and a

  • sed '2s/test1/new/' specifies line 2

  • sed '2,4s/test1/new/' specifies lines 2 to 4

  • sed '2,$s/test1/new/' specifies 2 lines after $ represents the last line

  • Print
    -p print text

  • = Print line number

  • | List lines, you can print out non-printable characters, such as \t

  • sed -n '/test/p' is similar to grep test. The former is more advanced and can use regular expressions. See Chapter 11.

10. gawk command

Is an enhanced version of awk
gawk '{print "hello"}' sets hello to display a fixed line of text string, so no matter what text is entered in the data stream, you will get the same text output
echo "me:hello world" |awk '{print $1}' ->me:hello uses spaces as delimiters by default
echo "me:hello world" |awk -F: '{print $1}' ->me **-F: You can specify: as the delimiter ** -F’[:/]’ You can specify multiple characters

Some common processing

  • Mathematical expressions
    gawk '$1 == 0 {print $0}' means that if the first column is 0, the entire line will be output.
  • if statement
    gawk '{if ($1 > 2) print $1}'
    gawk '{if ($1 > 2) {a = $1 *2 ; print a} else {print $2}}' test.txt
  • while,for statement similar to if

11. Regular expressions

> Can be used in sed and gawk

  • Anchor character
  • ^ anchors the beginning of the line
    sed -n '/^this/p' will only match lines starting with this
  • $ anchors end of line
    sed -n '/end$/p' will only match lines ending with this
  • Combine anchor points to delete blank lines
    sed '/^$/d'Highly recommended
  • period character
    The dot character can match any single character except newline characters. The period character must match one character
  • character group []
    echo "Yes" | sed -n '/[Yy]es/p'￼
    sed -n '^[0-9][0-9]$/p' will match two digits
    sed -n '[^ch]at$/p' ^ is placed in square brackets to exclude it.
  • Asterisk The asterisk indicates that the preceding character can appear 0 or more times
    echo "ik" | sed -n '/ie*k/p' can still be matched in this way

> Cannot be used in sed

  • Question mark Question mark indicates that the preceding character can appear 0 or 1 times
  • Plus sign The plus sign indicates that the preceding character can appear 1 or more times
  • Curly brackets {m,n} indicates that the preceding character can appear m to n times
    By default, gawk does not recognize regular expression intervals. You must specify the gawk command line option –re-interval.
    echo "beet" | gawk --re-interval '/be{1}t/{print $0}'
  • Vertical lines Vertical lines represent or
    gawk '/cat|dog/{print $0}'
  • Expression grouping ()
    gawk '/(c|b)a(b|t)/{print $0}'￼

1.2 $PATH executable file path variable

When executing a command “ls”, the system will search for an executable file named ls in each defined directory according to the PATH setting to execute the command.
Take $PATH/usr/local/bin:/usr/sbin:/usr/bin:/root/bin as an example. If you use root permissions to move /bin/ls to the /root folder, you cannot execute the ls command in this case. Only when you use the command PATH="${PATH}:/root" to add the ls path under /root to $PATH can you execute the ls command correctly.
If there are two ls, the ls searched first in the directory in $PATH will be executed.
